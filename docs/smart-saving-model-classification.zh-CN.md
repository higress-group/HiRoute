# 智能路由的决策模型

[English](smart-saving-model-classification.md)

在“模型 → 决策模型”添加内置决策模型或自定义扩展。配置供应商、模型、完整接入地址和凭证，保存并测试后，在路由中选择这个连接版本。保存或发布路由不会暗中发起模型调用；凭证复用现有受保护输入与存储，不需要单独管理 Secret。内置接入不需要另外部署 Jev 服务。

“保存并测试”用固定合成输入检查刚保存的准确版本，不读取真实会话、不执行任务、不产生胜任样本。编辑连接产生新不可变版本；已发布路由保留原选中版本，主动重新发布才会更换。列表展示最新版本，已保存的历史版本仍可用于发布。

按难度分流默认选中决策模型，也可主动选择启发式规则或自定义扩展。常规和主力模型继续使用现有候选选择器、排序和思考配置。内置连接的判断设置默认收起：简单概率阈值默认 0.8，胜任下限默认 0.5，简单/复杂与胜任评分提示词均可修改。

每条新用户消息重新决策。使用内置连接时，本次简单概率达到阈值，且没有适用的完整低胜任评分，才选常规组；复杂或本次有效低分选择主力组。保护必须来自本次新返回的完整评分，绑定上一实际阶段，与本轮同类别且发布配置、评分标准兼容。无评分、部分评分不会延续旧保护；新轮次也不会无条件退回常规组。工具续接与重放仅在同轮可识别、历史连续且决策可复用时沿用冻结选择；压缩或历史重建导致消息不连续、决策无法复用时会重判。“优先保持当前模型”仅限于本次新选中的组。候选故障接力不能从主力降回常规或跨任务分支。

自定义分支先判断任务意图，例如写稿、审稿；每个分支配置常规模型和可选主力模型。内置连接的判断设置可以跟随计划，或复制整套后独立修改；恢复默认即重新跟随计划。没有主力模型就不判断程度，但仍记录胜任度。任务分类条件、程度判断标准、已执行阶段的评分标准是三种独立输入。

现有会话与计划页面分别显示实际组别/模型/思考配置、当时阈值、选择原因及该阶段最新胜任度；修改草稿不重解释已发布证据。

历史问题适用性是内置 System One 路由新发布时的默认行为，没有开关或背景设置。已有冻结路由到下次发布才切换；默认评分届时自动跟随当前默认，自定义文字及全部标准逐字保留。“恢复默认”恢复当前默认并保留阈值。不可用的上下文字段会在 Preview 指出范围与字段；已有发布和历史证据保持冻结。本地规则及自定义扩展不使用内置适用性协议。内置连接的简单概率阈值默认仍为 0.8，胜任下限仍为 0.5。

内容分为 `prior_context`、`assessment_stage` 和 `latest_user`。背景固定最多 8 个完整轮次，保留安全历史中已有边界的中断轮、状态未知轮及原始状态；不限制完整目标阶段轮数。预算导致目标部分保留后省略适用性判断且不回填历史；部分评分不能触发历史保护。当前输入不静默截断，也不加入工具结果正文。

只有历史低分已通过原有归因、版本、分支、评分标准和完整性约束时，适用概率达到 0.5 才保留保护，低于 0.5 解除历史约束；适用性判断不可用时保守保留保护。难度有效时，无论当前任务简单还是复杂都评估保护；解除后复杂任务仍按难度选择主力。上一实际阶段已使用主力时不会出现第三组。它不转移旧分数，也不改变同轮继承和候选故障接力。机会按当时记录的动作统计，同一范围可能混合不同时期的规则，比例不能视为统一规则的效果比较。

连接页保留单一“测试连接”及原契约，固定示例采用当前默认请求格式。路由编辑器没有独立测试。CLI 和验收诊断可显式验证一次 19 问的最大支持形状，复用实际传输与解析。显式测试可能消耗配额；打开、保存和发布不会暗中探测。

计划和会话统计覆盖匹配范围内所有保留决策，不受阶段分页及模型/评分筛选影响。当前事件标记四类分类器协议；已知其他协议单独计数，不会让混合范围永久不完整。有认证格式证据的受支持早期记录也按已知旧发布计数；无法证明格式的无标记事件、缺失投影和读取上限仍形成覆盖缺口：计数可见，完整比例不可用。仅删除正文保留安全证据，完整事实删除或到期按现有流程移除。每个评分范围在冻结时记录其默认或自定义意图。比例描述路由行为，不声称准确率或质量提升。

CLI 沿用 `decision services list/apply/test` 和现有 routing 编辑、预览、应用流程。编辑结构使用 `smart.judgment`，自定义分支使用 `branch_routing.judgment`、分支 `primary_candidates` 和可选完整 `judgment`。自定义扩展自行决定策略，在已发布路由内直接返回类别和模型组；可选前段评分仅用于观察，HiRoute 不应用阈值或低分保护。扩展路由隐藏判断设置并保留原编辑值，切回内置连接时恢复。当前自定义扩展的执行投影不包含判断设置，携带旧判断设置的执行格式会被拒绝，不提供旧自定义扩展数据适配。内置服务已有的发布及 Operation 兼容支持保持不变。表单提供示例和唯一当前 OpenAPI。

详见 [HiRoute 扩展 API 语义](../decision-extensions/api/README.zh-CN.md)、[可选的 Jev 自托管部署](../decision-extensions/extensions/jev-decider/README.zh-CN.md)、[System One 映射](../decision-extensions/api/system-one-design.md)与[代码职责](code-map/decision-foundation.md)。早期开发期扩展结构不提供协商路径；内置服务已发布数据及共用观察历史继续使用登记的准入与恢复读取器，不包含已停用的旧自定义扩展专属格式。扩展不能选择工具。
