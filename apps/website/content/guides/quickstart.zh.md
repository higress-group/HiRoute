# 快速开始

先选择 macOS 桌面应用或 Linux 无界面版，再用一条固定模型路由完成第一次接入；熟悉基本路径后按需要启用智能省钱或任务委派。开始使用不要求部署外部决策服务。

## 1. 选择运行方式

- **macOS 桌面应用**：要求 macOS 15.0 或更高版本。公开安装包为自签名构建，下载后先核对 SHA256，再按 [macOS 安装与首次启动](/docs/install-macos/) 的说明打开应用。
- **Linux 无界面版**：面向服务器、远程工作站和自动化环境，按当前用户安装，不需要 `sudo`。按 [Linux 无界面版安装](/docs/install-linux/) 启动服务并通过 CLI 完成后续配置。

下面第 2–5 步展示桌面应用的可视化路径。Linux 用户在无界面版指南中通过同一套生产能力完成对应流程。无论使用哪种入口，都先确认本机服务已经就绪；模型路由、会话记录和任务执行都依赖它。

## 2. 连接一个模型

打开“模型”，选择“添加模型”。你可以接入应用列出的本机订阅，也可以在“高级接入”中选择“自定义 API”。

检查连接后，选择要加入 HiRoute 的模型并保存。页面上的“接入就绪”表示这项连接具备进入路由的必要资料，不等同于每个上游模型都已经完成一次真实推理测试。

## 3. 创建第一条智能路由

打开“智能路由”，选择“新建智能路由”：

1. 填写名称和使用场景，例如“日常开发”和“处理常规代码修改”。
2. 第一次使用建议选“固定模型”，把刚接入的模型加入候选列表。
3. 选择“启用”。只有已发布并启用的路由会处理新请求。

熟悉基本路径后，可以改用 [智能模型路由](/docs/model-routing/) 中的“智能省钱”或“免费优先”。

## 4. 连接你的 Agent

打开“Agent”，选择已发现的 Codex 或 Claude Code，然后：

1. 在“模型路由”中选择“启用”。
2. 打开“使用 HiRoute 模型路由”。
3. 勾选刚创建的智能路由，并把它设为默认选择。
4. 保存配置，按页面提示完成检查。

HiRoute 会保留恢复点。若以后停用模型路由，可以在“连接详情与恢复”中恢复接入前的设置。

## 5. 发起一次真实请求

回到你平时使用的 Agent，提交一个可以明确验收的小任务。请求开始后，在 HiRoute 的“会话”中查看实际路由、模型、用量和执行状态。
